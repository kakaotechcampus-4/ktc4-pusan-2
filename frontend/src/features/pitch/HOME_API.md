# 홈 API 연결

기준: 백엔드 PR #47, 커밋 ef043e1의 ID 필드 추가.

- `GET /api/pitches/`를 기존 인증 클라이언트로 호출합니다.
- `{ pitches: [...] }`의 각 피치에 필수 `pitch_id`, 각 Take에 필수 `take_id` UUID가 있습니다.
- 제목 → `/pitch/:pitch_id/edit`, 리포트 → `/takes/:take_id`로 이동합니다. 버전 번호는 ID로 사용하지 않습니다.
- `pitch_time`, `take_time`, `take_elapsed`는 초입니다. 점수와 증감의 null은 0과 구분합니다.
- 응답에 없는 날짜·주간 통계·Take 상태는 추정하지 않습니다.
- 썸네일 누락/실패는 기본 표지를 표시합니다. 목 데이터도 최신 ID 계약을 사용합니다.

## 검증 및 남은 작업

UUID를 포함한 응답의 링크 생성, null/0 처리, 빈 목록, 요청 실패를 계약 테스트로 확인합니다.

실서버 검증은 #47 반영 백엔드와 실제 로그인 세션이 필요합니다. `VITE_USE_MOCK=false` 및 `VITE_API_BASE`를 설정하고 Vite를 다시 실행합니다. 기존 인증/CORS 개발 주소(3000)를 사용합니다.

#47의 ef043e1에서 `module/take/repository.py`의 `TakeSummary` 뒤 쉼표가 누락되어 있습니다. 실서버 기동 전 백엔드 수정이 필요합니다. 현재 자료 편집·리포트 목적지 화면도 Stub이므로 완성된 편집/리포트 흐름 검증은 후속 작업입니다.

현재 검증은 프론트 계약 테스트와 목 화면 기준이며 실계정 통합 검증은 포함하지 않습니다.
