# 온라인 쇼핑몰 UX 개선

[슬라이드 1] 문제 발견

온라인 쇼핑몰을 이용하다 보면 원하는 상품을 찾기 위해 너무 많은 페이지를 이동해야 하는 경우가 있습니다.

특히 검색 결과가 많을수록 어떤 상품을 선택해야 할지 결정하기 어려워집니다.

[슬라이드 2] 검색 경험

현재 많은 쇼핑몰은 검색어를 입력하면 상품 목록을 보여주는 방식으로 동작합니다.

하지만 사용자는 상품의 가격뿐만 아니라 배송 기간이나 리뷰, 사이즈, 브랜드 등 여러 조건을 함께 고려합니다.

따라서 단순한 키워드 검색만으로는 사용자의 요구를 충분히 반영하기 어렵습니다.

3. 개선 방향

사용자가 검색어를 입력하면 추가적인 조건을 자연어로 입력할 수 있도록 하는 방법을 제안합니다.

예를 들어 "10만 원 이하이고 다음 주까지 배송되는 운동화"처럼 입력하면 가격과 배송 조건을 동시에 적용할 수 있습니다.

4. 기대 효과

이러한 방식은 사용자가 여러 필터를 직접 설정해야 하는 번거로움을 줄여줄 수 있습니다.

또한 사용자가 원하는 조건을 더 구체적으로 표현할 수 있다는 장점이 있습니다.

[슬라이드 5]

다만 자연어 검색이 항상 정확한 결과를 제공하는 것은 아닙니다.

따라서 검색 결과를 사용자가 직접 수정하거나 조건을 추가할 수 있는 인터페이스도 함께 제공해야 합니다.

6. 결론

좋은 쇼핑 검색 경험은 많은 상품을 보여주는 것이 아니라 사용자가 원하는 상품을 빠르게 찾도록 도와주는 것이라고 생각합니다.
