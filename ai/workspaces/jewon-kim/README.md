# jewon-kim

**Pitch Coach**의 컴퓨터비전(CV) 파트와 대본 전달 평가 파트를 담당합니다.

발표 연습에서 발표자의 **비언어적 행동**(시선)과 **대본 내용 전달**을 읽어 코칭 신호로 바꾸는 것이 이 워크스페이스의 범위입니다.

---

## 프로젝트

| 프로젝트 | 무엇을 하는가 | 상태 |
|---|---|---|
| [gaze-tracking](gaze-tracking/) | 웹캠 영상에서 시선이 **카메라**를 향하는지 **화면 아래 대본**을 향하는지 판정 | v1 개발 중 (local) |
| [script-coverage-evaluation](script-coverage-evaluation/) | 발표 대본을 슬라이드별 **평가 기준**으로 만들고, 발표 연습 STT가 대본 내용을 얼마나 전달했는지 **문장 · Key Point · 핵심 수치** 단위로 채점 | v1 개발 중 (local) |

## 이 워크스페이스의 규칙

### 버전 축이 두 개입니다

헷갈리기 쉬우니 먼저 짚습니다.

| | 무엇 | 어디서 올라가는가 |
|---|---|---|
| **모델 버전** (`v1`, `v2`, …) | 모델의 **출력 의미**가 바뀔 때 | `workspaces/jewon-kim/<project>/vN/` |
| **릴리스 버전** (`v1.0.0`, …) | 제품으로 묶어 내보낼 때 | `releases/vX.Y.Z/<project>/` |

둘은 독립입니다. 모델 `v1`이 릴리스 `v1.0.0`과 `v1.1.0`에 모두 실릴 수 있고,
반대로 모델 `v2`를 만드는 동안 릴리스는 계속 `v1`을 내보낼 수도 있습니다.

**모델 버전을 올리는 기준**: 백본 교체, 클래스 정의 변경, 캘리브레이션 방식 변경(gaze-tracking),
판정 단위·판정 값·점수 정의 변경(script-coverage-evaluation)처럼
**소비자가 받는 출력의 의미가 달라지는** 변화. 설정값 튜닝이나 임계값 스윕은
버전을 올리지 않습니다 — 그건 각 프로젝트가 기록하는 config hash가 추적합니다.

### `local` / `deploy`

같은 모델을 **어디서 돌리느냐**입니다. 모델 자체는 하나이므로, 두 환경은
`vN/README.md`(모델 기술 레퍼런스)를 공유하고 환경별 README만 따로 둡니다.

- `local/` — 실험·평가 리그. 웹캠이나 대본·STT 데이터를 붙이고, 데이터셋을 만들고, 지표를 재는 곳
- `deploy/` — 서비스 투입용 패키징

### 문서 규칙

각 레벨의 `README.md`가 맡는 범위:

| 레벨 | 답해야 하는 질문 |
|---|---|
| `<project>/README.md` | 이 프로젝트가 무엇이고, 어느 버전이 있고, 어디서 시작하나 |
| `<project>/vN/README.md` | 이 모델이 무엇을 보장하고 무엇을 보장하지 않는가 (**전체 기술 레퍼런스**) |
| `<project>/vN/local/README.md` | 어떻게 돌리고 어떻게 개발하나 (셋업·명령·함정) |

## 환경변수

프로젝트별로 읽는 환경변수입니다. 루트 `.env.example`에 반영이 필요하면 여기를 참고하세요.

### gaze-tracking

**둘 다 선택**이며, 없어도 기본 동작합니다.

| 변수 | 효과 |
|---|---|
| `PITCHCOACH_FORCE_CSV` | `1`/`true`/`yes`면 parquet 엔진이 있어도 gzip CSV로 특징 테이블을 저장. 첫 호출에서 캐시되므로 테이블 조작 전에 설정해야 합니다 |
| `PITCHCOACH_GIT_COMMIT` | 실험 기록에 남는 `code_commit` 값을 덮어씁니다. 커밋을 물어볼 git이 없는 환경(컨테이너·휠)용이며, **빌드에서 설정**해야 합니다 — 손으로 넣으면 기록이 거짓말을 시작합니다 |

### script-coverage-evaluation

노트북이 **현재 디렉터리부터 위로 올라가며 처음 만나는 `.env`** 를 읽습니다(`v1/local/.env` → … → `ai/.env`).
상위에 공용 `.env` 가 있으면 그 키로 **실제 LLM API 가 호출되고 과금**됩니다.

| 변수 | 필수 | 효과 |
|---|---|---|
| `OPENAI_API_KEY` | ✅ | LLM API 키 |
| `OPENAI_MODEL` | ✅ | 모델 이름. 엔드포인트가 허용하는 이름이어야 합니다(아니면 400). 검증한 모델은 `gpt-5.6-luna` |
| `OPENAI_BASE_URL` | | OpenAI 호환 엔드포인트. 없으면 OpenAI 기본 주소 |
| `RUBRIC_CONSISTENCY_SAMPLES` | | 대본 분석 노트북 12장 일관성 측정 횟수(기본 3). `1` 이면 끔 — 검증용 추가 호출이 없어집니다 |
| `STT_CONSISTENCY_SAMPLES` | | STT 평가 노트북 12장 반복 채점 횟수(기본 3). `1` 이면 끔 — 검증용 추가 호출이 없어집니다 |
