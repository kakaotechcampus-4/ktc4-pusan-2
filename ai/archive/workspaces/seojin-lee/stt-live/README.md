# stt-live

발표 연습 코칭 서비스 **Pitch Coach**의 실시간 말하기 속도 측정 프로젝트입니다.

STT(음성 인식)로 얻은 **단어별 타임스탬프**를 입력받아, 판정 구간의
**분당 발화 글자 수(CPM)**를 계산하고 **느림/보통/빠름** 세 단계로 판정합니다.

> 위치: `workspaces/seojin-lee/stt-live/`
> 워크스페이스 규칙(버전 축, `local`/`deploy`, 문서 범위)은 [../README.md](../README.md)에 있습니다.

## 다른 프로젝트가 이 프로젝트를 쓰는 법

소비자가 받는 것은 **`speed`와 `level`을 가진 `SpeedResult` JSON**입니다.
이 모양이 이 프로젝트의 계약이고, 모양이 바뀌면 모델 버전이 올라갑니다.

```json
{
  "speed": 428.57,
  "level": "fast"
}
```

- `speed` — 판정 구간의 **분당 발화 글자 수(CPM, Characters Per Minute)**. 침묵을 뺀
  실제 발화 시간을 분모로 계산합니다
- `level` — `speed`를 두 임계값(`SLOW_THRESHOLD=275`, `FAST_THRESHOLD=350`)과 비교해
  나눈 `"slow" | "normal" | "fast"`

> ⚠️ **입력은 STT 단어별 타임스탬프입니다.** 이 프로젝트는 음성 인식 자체를 하지 않고,
> 이미 STT를 거쳐 `{word, start, end}` 형태로 정렬된 단어 리스트가 주어졌다고 가정합니다.
>
> ⚠️ **아직 전송 계층이 없습니다.** 지금은 노트북에서 예시 단어 시퀀스로 CPM을 계산하고
> 임계값과 비교하는 셀을 직접 실행하는 형태뿐이며, 서비스에 붙이는 형태는 `v1/deploy/`에서
> 정해질 예정입니다.

각 필드의 의미와 계산 방식은 [v1/README.md](v1/README.md)를 보세요.
