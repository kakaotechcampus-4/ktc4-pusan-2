# 대화 에이전트 독립 최종 평가 문항 (v1 동결본, 검수용)

- 무엇: 에이전트를 고치는 작업과 맥락을 나눠 쓴 처음 보는 문항 60개. 고치기 전에 동결했고 최종 측정에서 한 번만 돈다(규칙 `RULES.md`).
- 상태: v1 동결(`manifest.json`의 파일별 해시) · 두 번째 사람 검수 중. 검수로 기대값이 바뀌면 최종 측정 전에 고친 문항만 v2 로 다시 동결한다.
- 이 브랜치는 검수용이라 merge 하지 않는다. 최종 측정이 끝나면 결과와 함께 본 작업 PR에 들어간다.

| 파일 | 내용 |
|---|---|
| `set/` | 문항 60개(파일 하나에 문항 하나, 형식은 `ai/research/chat-agent/evals/scenarios/schema.json`) |
| `RULES.md` | 미리 정한 규칙: 구성 · 작성 · 검수 · 동결 · 유사도 기준 · 실행 · 합격선 · 심판 보정 |
| `TARGET.md` | 이번 개선에서 더하는 동작(기능 문서 `docs/ai/features/chat-agent.md`에 반영 예정) |
| `REVIEW.md` | 다른 모델로 한 보조 검수 기록과 사람 검수 절 |
| `manifest.json` | v1 동결 목록(문항 · 규칙 · 스키마 · 채점 코드 해시, 동결 커밋) |
