# 대화 에이전트 독립 최종 평가 (기능 문서 13-5 · 13-8)

에이전트를 고치는 작업과 맥락을 나눠 쓴 처음 보는 문항 60개. 고치기 전에 동결했고, 최종 측정에서 동결 목록(문항 · 규칙 · 스키마 · 채점 코드 해시)과 같은지 확인한 뒤 **한 번** 돌렸다. 규칙은 문항을 쓰기 전에 정한 `RULES.md`(동결 대상)를 따른다.

| 파일 | 내용 |
|---|---|
| `set/` | 문항 60개(형식 `../scenarios/schema.json`, 관찰값 `trajectory`의 경로 검사 포함) |
| `RULES.md` | 미리 정한 규칙: 구성 · 작성 · 검수 · 동결 · 유사도 기준 · 실행 · 합격선 · 심판 보정 |
| `TARGET.md` | 문항이 기준으로 삼은 목표 동작(이번 작업에서 기능 문서 5 · 6 · 7-10 · 11-5에 반영) |
| `REVIEW.md` | 작성 때 다른 모델로 한 보조 검수와 두 번째 사람(팀원) 검수 기록 |
| `POSTHOC.md` | 공식 실행 뒤 실패 원인 분석(이 작업이 만든 버그 · 원래 약점 · 문항 기대값 문제)과 고친 것 |
| `manifest.json` | 동결 목록 v1(파일별 해시 · 동결 커밋 `c5b6db59`) |
| `results/` | 실행 보고: 봉인 기준선(`sealed-v1-*`, 동결 직후 고치기 전 코드 · 고정 순서), 공식 한 번(`final-v1.md`), 고친 뒤 강등 세트(`postfix-1-demoted.md`), 봉인 결과 해시(`sealed.sha256`) |

## 결과
모델 `gpt-6-luna`(기본 묶음) · 자료 모드 `approved` · 하이브리드 검색 · 문항마다 3번.

| 실행 | 코드 | 과제 성공률 | pass^3 | 경로 정확도 | 재계획 적합률 | 금지된 일 |
|---|---|---|---|---|---|---|
| 봉인 기준선 — 고정 순서 | `c5b6db59`(에이전트 = 고치기 전) | 0.394 (71/180) | 0.350 (21/60) | 0.656 (118/180) | 0.105 (6/57) | 0 |
| 봉인 기준선 — 고치기 전 에이전트 | `c5b6db59` | 0.528 (95/180) | 0.500 (30/60) | 0.822 (148/180) | 0.298 (17/57) | 0 |
| **공식 한 번(최종)** | `34850b28` (`chat_agent-0.12.0`) | **0.650 (117/180)** | **0.617 (37/60)** | **0.878 (158/180)** | **0.877 (50/57)** | 0 |
| 고친 뒤 — **강등된 세트, 독립 평가 수치 아님** | `a78696ea` | 0.800 (144/180) | 0.733 (44/60) | 0.883 | 1.000 | 0 |

- 합격선(`RULES.md` 7절: 성공률 0.90 · pass^3 0.80 · 경로 · 재계획 0.95 · 대표 · 안전 pass^3 1.00 · 금지 0 · 숫자 1.00)에는 **공식 한 번이 미달**이다. 기준선보다는 나았다(고치기 전 에이전트 대비 성공률 +0.12, 재계획 적합률 0.30 → 0.88, 고정 순서 대비 +0.26).
- 공식 실행 뒤 실패를 보고 에이전트를 고쳤으므로(`POSTHOC.md`), 규칙 6절대로 이 세트는 회귀 세트로 강등됐다. 고친 뒤 수치는 강등된 세트의 값이고 독립 평가 결과로 주장하지 않는다. 다음 독립 평가는 새 문항으로 한다.
- 실패한 문항 중 기대값 문제로 판정한 6개(`POSTHOC.md` C)는 동결본이라 고치지 않았다. 이 6개를 빼고 셈한 값도 독립 평가 수치로 쓰지 않는다.
- 근거성 판정의 사람 보정(`RULES.md` 8절)은 아직 하지 않았다 — 근거성 수치는 보정 전 값이다.
- 실행 기록 전체(`runs.jsonl`)는 크기 때문에 올리지 않았고, 봉인 결과의 해시는 `results/sealed.sha256`에 있다.

## 다시 돌리기 (`ai/research/chat-agent`에서)
```bash
.venv/bin/python -m chat_agent_lab.holdout verify --dir evals/final/set --manifest evals/final/manifest.json --rules evals/final/RULES.md --no-grader  # 문항 · 규칙이 동결본과 같은지
.venv/bin/python -m chat_agent_lab.evals --dir evals/final/set --set all --judge --workers 4 --search hybrid --out outputs/evals/final-rerun
```
채점 코드는 최종 실행 때까지 바뀌지 않았다(최종 실행 때 `verify` 채점기 포함 일치). 그 뒤 세트 도구(`holdout.py` 규칙 대조 · 오류 위치 가리기, `similarity.py` 읽기 실패 · 빈 쪽이면 2)를 고쳐 채점기 포함 대조는 이 두 파일이 다르다고 나오므로, `--no-grader`로 문항 · 규칙만 대조한다. 동결 목록에 규칙 해시가 있어 `--rules`는 빼면 실패한다.
